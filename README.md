## 💻 How to Run JavaScript Programs

Make sure Node.js is installed.

Check the installation:

```bash
node --version
```

Run an individual JavaScript file:

```bash
node JavaScript/Day-01/variables.js
```

Replace the file path with the program you want to execute.
